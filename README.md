# Static Web Page - Internship Task

## 1. Objective

The objective of this project is to convert a web design concept
into a functional static webpage using HTML and CSS.

## 2. Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Media Queries

## 3. HTML Structure

Semantic HTML elements were used to create a clear webpage hierarchy.

Main sections include:

- Header
- Navigation
- Hero section
- About section
- Services section
- Contact section
- Footer

## 4. CSS Approach

CSS was organized into separate sections for:

- Reset
- Header
- Hero
- About
- Services
- Contact
- Footer
- Responsive design

Flexbox and CSS Grid were used for layout management.

## 5. Responsive Design

Media queries were implemented for different screen sizes.

The webpage was designed for:

- Desktop
- Tablet
- Mobile

On smaller screens, multi-column layouts change into
single-column layouts and navigation/content spacing is adjusted.

## 6. Challenges

One challenge was maintaining the layout across different
screen sizes.

This was solved using:

- CSS Grid
- Flexbox
- Relative widths
- `clamp()`
- Media queries

## 7. Conclusion

This project demonstrates the fundamentals of converting a
design concept into a responsive static webpage using HTML
and CSS.
